# Sources

The model was trained on Randall Munroe's [xkcd color survey](https://blog.xkcd.com/2010/05/03/color-survey-results/).
The raw survey is downloaded separately and is not included in this repository.
The separately downloaded [curated color list](https://xkcd.com/color/rgb.txt) declares CC0 in its header.

[gpu-lexer](https://github.com/vercel-labs/gpu-lexer) inspired this project.
No gpu-lexer code or weights are included.

Dependency licenses remain with their respective packages. The MIT license
covers this project's code and included model weights.
